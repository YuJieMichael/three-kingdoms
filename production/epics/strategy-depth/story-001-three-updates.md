## Scope

用户选择建议 1、2、3：三场正式军令混合遭遇，已有城市固定粮城／矿城／关隘差异，赵云接应撤军与马超冲阵。继续图片抓将、爵位和招降容量、地图逐步发现、实际负重及资源入库允许爆仓。沿用五入口和折叠长说明；不新增远程项目、费用、多人计谋、随机养成或全新章节。

## Acceptance Criteria

- [x] AC-1：三场遭遇按野战5／精锐7／攻坚10进度逐步显示，未到只有下一进度，普通将可反制。普通胜利有基础军功，首次限损／限回合达标额外45／55／70军功一次，不阻塞章节。
- [x] AC-2：敌准备、固定战场位置及真实回合事件进入正式引擎；场景统领身份与野将俘获分离、存档严格校验；共享自动模式明确拒绝派出／启动而不静默降级。
- [x] AC-3：古渡与青石粮城本城粮食毛产量+20%，白沙矿城木石铁+15%，赤岗关隘本城新派队行军时间-20%；主城和平地自建均衡，不叠到其他城、不减维护、不补算既有在途时间。
- [x] AC-4：城市卡片／目标详情显示占城收益，派遣／运输预览反映实际耗时；切城与离线仍准确，预览不修改存档。
- [x] AC-5：赵云用一次身份战法与1筹策、准备轻骑主攻击，响应轮接应300距离内后退友军最多1.5倍，成功友军放弃本轮主攻击，边界／火区照常生效。
- [x] AC-6：马超准备轮骑兵实际前进并牺牲主攻击，响应轮真实前进接触非固守近战目标后最多推退200，响应轮主攻击消耗；固守可完全反制，不附送伤害，不以被动位移充当主动准备。
- [x] AC-7：新version2支持新身份与场景，旧version1进行中战斗维持原身份；筹策／位移／攻击消耗可重载，伪造身份或不合法记录拒绝。两个独立教学不动正式兵将资源奖励。
- [x] AC-8：必要定向检查与桌面／手机浏览器实际操作保留证据，构建权威副本后兼容检查；大型本地回归、自然长局、真人平衡仍另批集中做。
