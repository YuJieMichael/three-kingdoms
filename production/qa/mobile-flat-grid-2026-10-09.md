## 浏览器验证

使用 Codex 内置浏览器，项目无缓存server.cjs，准备的合法单机测试档（官府1级，11座城内建筑，8块资源田）。截图是布局夹具，不代表玩家自然进度。

| 检查 | 证据 |
| --- | --- |
| 360/390/440px 六列、无横向溢出 | 最小格宽分别53.83/58.83/67.16px，高82px；超过44×44要求 |
| 城内33个按钮，官府为一个四格按钮 | 全部格中心与两处边缘elementFromPoint命中自身；实际点官府四个象限都开官府详情 |
| 城外12个地块，不错位 | 全部中心与边缘命中自身；实际点4号铁矿右下边缘打开4号铁矿 |
| 施工与取消入口 | 开启自动升级排入1号、5号农田；暂停后工程保留，地块显示倒计时，详情显示取消施工 |
| 改建收纳 | 默认只见升级；展开更换产业显示其他三种；点伐木场进入明确确认改建，关闭未改建 |
| 空地 | 未建地块仍可见，四种产业直接显示；目标测试覆盖 |
| 开局自动升级 | 营造直接可点，开关可用；实际开启/停止后当前弹窗立即更新，资源扣除与两条工程可见 |
| 键盘 | 3行2列空地右移到官府；保留逻辑索引跳过reserved格 |
| 跨断点 | 手机→1000px→手机自动更新；1000px有scene-stage且无flat grid |
| 拖动 | 内置浏览器鼠标纵向拖过城内、城外格子均未开详情；现有touch-tap测试覆盖移动后抑制点击 |

**限制：未使用真机Safari。** 内置浏览器鼠标拖动不能替代iPhone触摸滚动；实际Safari手势和横屏触摸仍需负责人发布前在手机验证。CSS允许pan-y，世界地图拖动未改。
