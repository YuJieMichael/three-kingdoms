# v0.25.0 据点、抓将与征战闭环验收

日期：2026-10-05。范围：任务据点按进度显示、首页主线、野地抓将、兵种速度行军、战斗反馈与自动返回地图、主动黄巾守城、阶段补给。

- 根目录 JS/CJS 语法及 `git diff --check` 通过。Graphify 按既有 code-only 排除参数刷新，并以 `cluster-only . --no-label` 重建本地图谱；嵌套引擎函数继续按源码验证。

## 收益与覆盖边界

两个准备好的中期战斗检查点观察到：300 弓兵/30 民夫对三级野地，分别实际带回 8124 与 13145 资源，永久补兵成本 1900 与 0。账本只比较实际资源与永久补兵成本，尚未覆盖行军粮、维护、人口、时间和正常玩家成长分布；不能据此宣布经济平衡完成。

当前仍为单机 PVE，野将线索稳定保存；多人共享世界、同时抢将的服务端仲裁尚未接入。移动真机、完整自然新手抓将节奏、高级野将、全量与长局在下一轮集中验证。
