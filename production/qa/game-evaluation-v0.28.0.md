## First Impressions / Gameplay Flow

真实新档从官府1级、四资源各5,000开始。打开十阶礼包可看首阶四资源各40,000及黄金10,000，领取后引导指向民房；民房费用、85秒队列和城守经验可见。完成后实际获得城守经验10。地图任务据点只显示当前河畔荒田，后续任务地标不可用，减少提前暴露所有目标的负担。

机器可以读到明确目标与合法按钮。**玩家是否理解目标／控制、觉得兴奋或无聊：NOT ASSESSED。** 这次没有真人盲测，也没有自然玩到第一批弓兵或首战；不以85秒建设推断完整新手节奏。

### 做得较好的部分

- **经营开始有分工。** 两城资源、官府与城守独立；20,000木材运输实际到货，超容量仍足额入库，运输队返城及重载没有重复发奖。兵城、资源城、投石城已有不同用途。
- **远征过程可追踪。** 行军、驻扎、召回、返回和缴获账本有连接；斥候需要真实派出，报告区分“兵种已知／数量未知”与有效期，失去的斥候和幸存归兵可核对。
- **抓将有门槛链。** 客栈、画像、爵位、容量、黄金／珍宝及培养把多个系统联系起来；纯骑速度与弓兵战力分别承担寻将与作战用途。
- **宝物阅读负担降低。** 手机背包四列小格、名称数量常显，长用途打开详情；商城两列卡片与折叠说明实测没有横向溢出。它改善可读性，尚不能证明长期乐趣。

### Pain points / Confusion points

| 优先级 | 设计问题 | 证据与影响 |
| --- | --- | --- |
| P1 | 名将收集多，行为差别少 | 当前十二条定义及四专长主要影响属性和倍率；相同兵种下容易继续选择数值最高者。用户同质化反馈与源码一致，影响大小待真人测量 |
| P1 | 后期缺持续争夺的利益 | 多城、抓将、运输已有用途，但玩家城市易主、宣战、保护与联盟领土目标仍未串起。反复征战可能继续替代长期战略选择 |
| P1 | 竞争经济政策未定 | 共享命令仍能领每日1,000试玩元宝；现商城可兑换合计1,100,000黄金／日。缺粮只归零而没有进一步惩罚，削弱养兵与分城供粮的约束 |
| P2 | 信息越来越多，关键任务要更突出 | 新手可找到下一步，城多后还有切城、运输、援军、培养和军情。是否抵消策略收益需记录实际点击和误操作，不凭界面数量判定 |
| P2 | 三种战斗的体验不一致 | 普通战斗逐队移动／目标／即时反击；NPC守城与共享自动掠夺更简化。新增名将行为若只接一条路径，会造成适用范围和强弱理解混乱 |

Moments of delight、是否愿意再玩、难度是否适中、期望会话长度均为NOT ASSESSED，没有替玩家填写情绪。

## Feature-Specific Feedback

**名将：从数值替换变为打法选择。** 首批草案收紧到黄忠预备射击、魏延诱追目标、徐庶提前揭露。每项都写条件、筹策、主攻击消耗、预兆、失效与反制；普通将仍能反制。它们尚未实现和调平，详见[系统草案](../../design/gdd/hero-stratagems.md)。

**计谋：先让对手有应对机会。** 当前锦囊effect为空、不能使用，出征指令不等于计谋。首批提议公共察伏与火攻封路，不再收费出售原本免费的后退／指定目标。只在现有一维战场验证，没有假定二维绕后、天气或粮道已经存在。[原版计谋](https://web.4399.com/rxsg/yxzl_jmxt_30_759.html)可作为欺骗、拖延和反制的灵感，本作方案须独立验证。

**后期：给城市不同的战略价值。** 建议黄巾城市→县城→郡／州城，连接联盟补给与作战位置；同步设计宣战预警、资源保护和败方恢复，之后再做完整外交与盟友运输。[原版宣战](https://web.4399.com/rxsg/yxzl/gcld_30_777.html)和[联盟领土](https://web.4399.com/rxsg/wjgl_11_8916.html)都有相应层次，当前没有完整实现。先不继续扩整套坐骑、宝石和高级养成来代替争夺目标。

**经济：确认正常玩家能否补回军队。** 新手任务重复奖励已削减，十阶礼包黄金仍合计1,000,000；礼包是有限补给，试用货币是重复供给，两者应分别核对。下一轮记录正常首弓、战损、补兵与运输收入，再确定共享服试玩货币、缺粮与保护政策。现报告不擅自改价或扣兵。[经济复核](playtests/studio-v0.28.0-economy.md)含来源与计算。

**手机＋电脑：客户端可共用，服务器保证归属。** 私人云档、共享修订CAS、幂等、唯一名将／城址、援军与SQLite/Auth开发服务已有实际检查。正式独立Supabase项目尚未选定、迁移和Edge未部署；不能把本地SDK成功或同actor竞争测试说成百人正式运营。

## Action Routing / Top 3 Priorities

1. **设计变更：三将＋两计谋＋三场教学演练。** 先审行动事件与支持矩阵，再做普通PvE原型；确认玩家换将会换打法。后续守城／共享自动策略独立接入。实现前按design-system／design-review核对条件与依赖，不把本次草案发布当机制上线。
2. **经济与后期：资源链＋城市价值。** 先确认试玩元宝和缺粮规则，集中长局记录首弓、损失／缴获／实际入库、多城管理与补兵；经balance-check再调数字。领土争夺与宣战／保护／失败恢复配套设计。
3. **质量与打磨：可靠跨设备＋低操作成本。** 完成独立后台部署，再逐级真实玩家容量测试；同时记录结算确认次数、手机点击负担与战报理解。已修缺陷保留定向证据；全量回归、自然长局与真手机按用户约定集中安排。
