## 实现范围

普通单机新战斗使用 `rules3`，接入黄忠「蓄弦先射」、魏延「佯退诱追」、徐庶「料敌先机」，以及普通将也可使用的「察伏」「火攻封路」。每方每战 3 点筹策，每轮最多提交一次；火攻花 2 点，其余花 1 点。数字属于首批原型假设，未调平。

三场固定教学复用逐队战斗结算，但保存在正式 `Game.state` 之外的临时会话。至少观察两轮、达到教学目标后结束；“演练目标达成”表示已看到指定战法作用，不表示正式战斗歼灭所有敌军。

| 场景 | 本轮支持状态 |
| --- | --- |
| 普通单机新出征、逐回合战斗 | 启用 `rules3` 与新计谋 |
| 三场独立教学演练 | 启用；不消耗或赠送正式兵将、资源、经验、奖励 |
| 旧存档中已经开始的 `rules2` 战斗 | 保持旧规则，不注入新能力 |
| NPC 城防 | 保持旧规则，禁用新计谋 |
| 共享世界／服务端自动结算 | 保持旧规则，禁用新计谋；界面说明支持范围 |

新增用例覆盖双方筹策与提交上限、非法操作原子性、取消不退款及主攻击预留、同命令重放与冲突命令拒绝；还覆盖 JSON 重载后筹策、准备、揭露、攻击预算与历史一致性。非法筹策、身份、准备、预留、阶段及伪装快照被拒绝，没有为兼容放宽存档校验。

黄忠用例区分实际从射程外进入、已经在射程内、没有进入事件、察伏取消与下一轮恢复。真实引擎顺序检查为：预备射击 → 即时反击 → 对方正常主攻击 → 合法反击；触发射击不多送一份主攻击，反击不引发反击链。

魏延用例检查实际后退、诱兵现存训练成本至少为目标的三分之一、精确门槛与无退路拒绝，防止一骑诱走大军；仅仍前进的近战目标追击，坚守目标不被强制移动，也不增加移动距离或主攻击。

火攻用例检查左右进入和一次跨越整段的截停、唯一全场火区槽、生效时区内已有兵队导致失效、筹备攻击代价及后续恢复。徐庶只能揭露已提交且锁定的目标；对手视图和未揭露教学内容没有确切火区坐标，也不暴露未来命令。

真实招募链用例分别执行三将的画像购买 → 正式战斗取胜与俘获 → 返城 → 正常黄金招降，再验证出征身份、旧行军缺失身份快照补齐、战后回执与重载。教学用例另检查重试、退出、初始化、导入、非法兵队序号及正式战斗进行中拒绝启动演练，正式状态和存档字节不被教学改动。

## 已修复的验收发现

1. **身份及存档伪装**：新正式战斗身份严格绑定真实将领的稳定 `wildLine`、行军冻结快照与敌方来源。不能仅同时伪造技能领导者和属性快照把普通将变为名将。
2. **旧行军快照**：旧已出发行军缺少身份时，仅从其真实将领补齐稳定身份；旧已经开始的 `rules2` 战斗不升级规则。
3. **教学结束与信息边界**：教学至少观察两轮、达到作用目标即可结束，不要求全灭；火区课描述不提前泄露确切坐标。结果文字区分教学目标与正式胜利。
4. **正式预览计时**：打开计谋报价或取消确认时暂停正式自动计时，避免查看条件期间指令冻结；返回指挥页可自行开启。
5. **攻击预留与回顾**：合法取消、未触发或被识破不恢复已预留主攻击；界面保留其说明。火区熄灭后仍可看本轮回顾；追击成功后目标阵亡的日志说明追击“结束”。

这些修复由新增必要用例或最终浏览器检查补证。最后 26 项受影响复查包含已计数用例，没有增加 80 的唯一总数。

主代理最后重新执行新增 18 项，全部通过；9 份受影响 JavaScript 通过语法检查，`index.html` 的 63 个版本化资源统一为 `0.29.0`。共享工厂包含 25 份源码，其源哈希前缀为 `1ab8f1524509`；这些是本地构建证据，不替代远端发布回执。

## 尚未评估与发布边界

- 黄忠需要第 N 回合准备、第 N+1 回合出现实际入射程事件。短野战中可能错过敌军首次入射程；可触发机会频率、是否值得牺牲两轮主攻击、与普通弓兵打法的收益比较均待真人或后续专门数值试验，不能声称已证明平衡。
- 魏延三分之一成本门槛、3 点筹策、火区长度及整体强度仍是原型数值。自然长局、不同兵种规模与将领养成阶段尚未评估。
- 浏览器使用桌面和手机尺寸模拟；没有真实手机设备验收，也没有真人理解度结论。NPC 城防、共享指挥和其他候选名将仍未接入本轮新机制。
- 共享兼容用例不等于 100 个真实玩家压力测试。远程 Supabase 尚未部署，本文件不宣称其权威结算或线上容量已验。
- 远端 CI 与 Pages 由主代理发布后独立核对。当前文档仅记录本地必要验收通过，不能据此推断线上已更新。
