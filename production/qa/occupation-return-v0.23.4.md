# 野地占领后返回 v0.23.4 验证

日期：2026-10-05。用户要求占领时可选择胜利后返城，不选则驻扎。

## 行为与兼容

野地配兵的占领模式增加默认未勾选的“占领后返回”。未勾选仍驻扎并耗粮翻倍，可采集或召回；勾选则沿原返城计时返回，地权、产量加成与奖励保留。采集仍需要主将率驻军。任务据点、城池与军令沿原返城规则。

returnAfterOccupy 随每支出征保存，旧出征缺字段默认驻扎；出征、次要队伍、结果和历史战报的字段为可选严格布尔。非法输入在 tick 和扣兵之前拒绝。胜利先结算地权与奖励，再决定驻扎或返城；返回与伤兵沿既有一次结算流程。战败不取得领地。掠夺、任务与军令忽略并规范化此选择。v0.23.3 的负重及爆仓结算保持不变。

勾选框在预览之外，切换掠夺模式时隐藏并禁用，切回占领保留本次选择；定时更新不重建输入。在外部队显示占领成功后的去向，战报、地图和帮助同步说明。
