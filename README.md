# 三国城志 · 单机 PVE 原型 v0.25.0

城内建设、资源田经营、研究、招兵、配将和掠夺／占领的手机浏览器原型。以 4399 第一代《热血三国》现存手册为规则资料，名称、人物和视觉资产采用原创内容。现存资料未锁定具体历史补丁，明确的数值使用手册表；缺失数值按用户选择标为试玩值。

## 运行

在线试玩：[打开三国城志](https://yujiemichael.github.io/three-kingdoms/)。GitHub Pages 从 `main` 分支根目录自动发布，推送修改后网页会更新。

在此目录执行 `npm start`（或 `node server.cjs`），打开 http://127.0.0.1:8137/ 。无 npm 依赖，无构建步骤。存档保存在当前浏览器。继续开发与保存更新请看 [修改指南](DEVELOPMENT.md)。

静态部署保留全部前端 HTML、CSS、JavaScript、icon.svg、manifest.webmanifest 和完整 assets 目录，保持相对路径。server.cjs 仅供本地运行。

## 试玩顺序

新档先建设民房、军营、校场，在城外发展农田。等待人口增长后训练义兵，逐步发展书院、战斗科技、长枪兵与弓箭兵。出征需要空闲主将，城守、主将与军师任职期间不能带兵离城。缺少人口时优先扩民房，人口不足不能靠多军营解决。

可在城务／设置选择 ×1、×10、×60 的试玩倍率。倍率影响人口和新开启的建造、训练、研究、行军工期；资源生产、税收和军队耗粮按真实时间计算，不乘试玩倍率；已建立队列不改变结束时间。持续道具、野地降级、冷却和离线 8 小时上限使用真实时间。

## 战斗

初始距离为参战兵种最大射程 +200。速度决定行动先后，同速守方优先。每种兵独立选择向前、坚守、后退与优先攻击目标；移动后仅攻击射程内的敌军，目标不可攻击则自动改选。双方互在射程内时，被攻击方幸存部队反击一次，不连锁反击。

指令可保存为出征默认战术，战斗中改令不改变其他队伍。后退到己方边界不会离开战场，没有整队撤退按钮。进入战斗后默认每 30 秒推进一回合，显示剩余秒数；点击「下一回合」立即结算并重新开始 30 秒计时。可暂停倒计时后逐回合手动推进，再开启时从 30 秒开始。试玩倍率不改变战斗回合间隔，切换游戏内页面不暂停；浏览器关闭／被系统冻结时暂停战斗，重新载入存档后保持暂停，需手动开启。30 回合上限、伤害及兵种克制公式为试玩规则。
