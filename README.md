# 山河策 · 网页经营与共享世界策略原型 v0.34.31

城内建设、资源田经营、研究、招兵、配将和掠夺／占领的手机浏览器原型。以 4399 第一代《热血三国》现存手册为规则资料，包含历史名将与原创将领，视觉资产为本作制作。现存资料未锁定具体历史补丁，明确的数值使用手册表；缺失数值与新增玩法标为试玩值。

## 运行

在线试玩：[打开三国城志](https://yujiemichael.github.io/three-kingdoms/)。GitHub Pages 从 `main` 分支根目录自动发布，推送修改后网页会更新。

在此目录执行 `npm start`（或 `node server.cjs`），打开 http://127.0.0.1:8137/ 。单机前端无需安装依赖或编译，进度保存在当前浏览器。SQL 验证使用独立开发依赖；在线后台另有构建与部署步骤。继续开发请看 [修改指南](DEVELOPMENT.md)。

静态部署保留全部前端 HTML、CSS、JavaScript、icon.svg、manifest.webmanifest 和完整 assets 目录，保持相对路径。server.cjs 仅供本地运行。

**云端尚未远程启用。** 账号、私人云档与共享世界接口已实现并完成本地定向验证；需要先确认独立 Supabase 组织／项目与费用，再按 [后台部署指南](online/README.md) 启用。当前 Pages 单机试玩不代表已经开放多人服务器。

## v0.33.0 更新

新增县 → 郡 → 州 → 都城的行政辖区路线。指定下级城池由玩家本人占领后才能进攻上级，洛阳还需完成第三章；联盟领土只聚合展示，不代替个人门槛。名城采用不同守军，上级强化城门，并有稳定发展奖励；连续攻城将民心降到零以下后建立真实分城。县、郡、州、都城资源田上限为12／15／18／18级，本城黄金税收分别增加10%／20%／30%／40%；高阶田费用、工期及收益标为本作参数。未来任务据点继续按当前进度显示。

新守城预设保存留城／出城、各兵种前进／固守／后退与目标，开战时冻结并真正参与移动与攻击。默认在玩家点击迎战后自动完成战斗，也可关闭自动结算逐回合查看；预警到时不会自行开战。新战斗伤兵进入所属城的伤兵营，不能直接出征或搬运，需支付黄金治疗，可按兵种、一键或自动治疗；未治伤兵占人口并按双倍养兵粮耗维护。旧版已经归队的伤兵不追回，进行中的旧守城保留原结算。

民怨纳入民心目标，低民心、高民怨与断粮出现一小时预警，安抚和补粮可阻止后果。天灾／天赐由玩家主动开启，祭天与自动安抚支付实际物资。将领薪俸按每真实小时「等级×20黄金」从所在城支付，欠饷降低忠诚，补发可挽救；忙碌将领忠诚归零时等待返城再离开，城破俘将有24小时招降期限。旧档从迁移时开始计费，不追缴旧时段；资源和薪俸共用最近8小时的离线结算窗口，既有队列仍按原截止时间完成。

## 试玩顺序

新档先建设民房、军营、校场，在城外发展农田。等待人口增长后训练义兵，逐步发展书院、战斗科技、长枪兵与弓箭兵。出征需要空闲主将，城守、主将与军师任职期间不能带兵离城。缺少人口时优先扩民房，人口不足不能靠多军营解决。

可在城务／设置选择 ×1、×10、×60 的试玩倍率。倍率影响人口和新开启的建造、训练、研究、行军工期；资源生产、税收和军队耗粮按真实时间计算，不乘试玩倍率；已建立队列不改变结束时间。持续道具、野地降级、冷却和离线 8 小时上限使用真实时间。

## 战斗

初始距离为参战兵种最大射程 +200。速度决定行动先后，同速守方优先。每种兵独立选择向前、坚守、后退与优先攻击目标；移动后仅攻击射程内的敌军，目标不可攻击则自动改选。双方互在射程内时，被攻击方幸存部队反击一次，不连锁反击。

指令可保存为出征默认战术，战斗中改令不改变其他队伍。后退到己方边界不会离开战场，没有整队撤退按钮。进入战斗后默认每 30 秒推进一回合，显示剩余秒数；点击「下一回合」立即结算并重新开始 30 秒计时。可暂停倒计时后逐回合手动推进，再开启时从 30 秒开始。试玩倍率不改变战斗回合间隔，切换游戏内页面不暂停；浏览器关闭／被系统冻结时暂停战斗，重新载入存档后保持暂停，需手动开启。30 回合上限、伤害及兵种克制公式为试玩规则。
