# 名将与计谋设计及两批原型

状态：IMPLEMENTED PROTOTYPE，v0.32.0，2026-10-05。首批三将、赵云／马超、五场教学和三场正式军令遭遇已实现；本版新增荀彧／庞统的本城内政职责。未调平、未获真人试玩结论，其余名将与联网计谋仍为提案。实际规则以 RULES.md 为准。

## Summary

让主将改变行动方式，让计谋改变距离、情报与时机的判断。首批用黄忠、魏延、徐庶和两个公共计谋验证不同打法，再扩充数量。初稿审查已移除与黄忠重复的公共伏击、只有收费而没有新收益的佯退／突破按钮。

> **Quick reference：** Category：Gameplay；Layer：Feature；Priority：Post-MVP（由 game-brief 推导，尚无 systems-index）。Key deps：回合事件、画像招降、将领成长、战报、快照与权威结算。

## Overview

当前十二条野将定义主要用属性、招募条件和兵种 bonus 区分，四条专长主要增加倍率。保留这些成长基础，另外赋予名将稳定身份机制。每支军队仍只有一位主将；不增副将槽，不把几位名将的专属能力叠进同一队。

抓将仍要求画像；纯骑兵的速度服务远距离寻将，弓兵继续承担常规远程主力。普通将也能施计和反制，不让唯一名将成为应对另一名将的必需门票。

## Detailed Design

### 第一批公共规则

- 原型每方每战3点筹策，不恢复；每回合最多提交1个新计谋／主动身份战法。已准备能力下一回合触发不再占提交名额；每位主将的主动身份战法每战最多提交1次。数字均为待调假设。
- 普通攻击、前进、坚守、后退、指定攻击目标继续免费。当前智谋不额外改变费用或范围，避免未定义倍率。
- 第N回合准备并显示施计队、类型与剩余准备回合。目标／火区位置提交时锁定，普通对手在第N+1回合响应指令冻结后才看见具体目标；徐庶能提前揭露一个已提交目标。准备不能事后改目标。第30回合拒绝需要下一回合的准备，非法提交不收费。一轮准备仅适用于火攻、黄忠和魏延；察伏在提交的当前回合移动前取消此前已准备的射击，徐庶在当前响应冻结前揭露已宣布目标，两者仍占当前回合提交名额。
- 第N+1回合先冻结响应指令、处理察伏，再按现有速度顺序逐队行动。每次实际移动后检查触发攻击，然后处理该队剩余普通攻击和即时反击；整轮结束后准备／火区到期。不改成全军先移动、再统一攻击。
- 普通攻击与触发攻击共享该队该回合的一次主攻击机会。反击保留现有“每次受击且仍存活、距离合法可反击”的规则，没有回合总上限；反击不能引发再次反击。若以后要限制反击次数，另行调平。
- 非法提交不扣费；合法宣布后取消、被识破、没触发或兵队被消灭都不退款。取消必须在响应指令冻结前；已经牺牲的前一回合攻击不恢复。取消仍损失已经锁定的筹备／触发回合主攻击，从后续回合恢复正常攻击。黄忠第N+1回合须继续坚守，改令视为取消；同一兵队的主攻击机会不能同时用于预备射击和筹备火攻。

### 两个公共计谋

| 计谋 | 原型规则与成本 | 对手反制 |
| --- | --- | --- |
| 察伏 | 花1点，选择一支公开正在准备触发攻击的敌队；在提交的当前回合移动前取消该次准备。无须拥有徐庶，不泄露其他准备。第一版只取消黄忠预备射击，不取消普通攻击、火区或魏延诱追 | 主动取消仍损失本轮预留主攻击，从后续回合恢复正常攻击；察伏不是永久沉默。察伏生效后原准备队仍失去该回合预留的主攻击，必须明确显示 |
| 火攻封路 | 花2点，以一支己方作战队施计并牺牲第N回合主攻击，在双方队伍之间选择长度100的空区间；准备一整回合，第N+1回合生效一轮。影响双方，从左侧进入停在左边界外1单位，从右侧进入停在右边界外1单位；即使预计终点越过整个区间，也在首次进入处截停，剩余移动丢失；没有生命百分比伤害 | 暂缓前进、提前改变位置或远程压制。若生效时已有队伍在区间内，整段火攻失效且不退款，避免凭空把脚下变成陷阱 |

整场战斗的火区槽只许一段，宣布时即占用；已有准备或生效火区时，新提交非法且不收费，不叠加、不覆盖城门。区间包含两端，左端至少为1、右端至多为战场长度减1；是否已有部队占据区间，在第N+1回合响应冻结后、任何移动前统一检查；整轮结束熄灭并释放槽。提交时空区间坐标先只对施计方可见，敌方能看到施计类型、施计队及倒计时；响应冻结后公开区间。当前一维战场没有左右绕行，因此不写“侧翼绕火”。位置单位沿现有战场坐标。

首批不做断粮、地图伪装、全军点燃或随机成功率。原版灵感见[4399计谋一览](https://web.4399.com/rxsg/yxzl_jmxt_30_759.html)，本表是本作新设计，不是原版规则复述。

### 三位首批名将

| 名将 | 独特行动 | 明确代价与反制 | 玩家需要改变什么 |
| --- | --- | --- | --- |
| 黄忠 · 蓄弦先射 | 花1点，弓兵第N回合坚守并放弃主攻击；第N+1回合等待第一支敌队实际从射程外移动到正常射程内，在该敌队攻击前使用弓队本回合主攻击 | 已在射程内的队不算“进入”；每次准备仅触发一次；整轮没有进入则失效，弓队不能补普通射击。对手可坚守、盾兵探阵、察伏或在射程外压制 | 用两轮输出机会换先手，判断谁会先接近；不会增加一份免费伤害 |
| 魏延 · 佯退诱追 | 花1点，选择一支己方长枪／轻骑诱兵及一支敌近战队。诱兵第N回合实际后退并放弃主攻击；第N+1回合若目标仍选择前进，其移动停止目标与主攻击目标改为诱兵，接触不到不改打别人 | 不强迫坚守／后退队前进，不增加移动距离；射击队、工事无效。诱兵现存训练成本须至少达到目标队的1/3；目标可坚守、不追，或让其他队射杀诱兵。门槛待调平 | 利用真实距离把追兵拉离其他队，给远程争取输出空间；不是免费后退换个名字 |
| 徐庶 · 料敌先机 | 花1点，第N回合揭露一个敌方已提交准备的确切目标及条件，例如魏延的诱兵／追兵、火攻区间；自己仍按正常规则移动与攻击 | 不取消敌计、不读取未来未提交命令、不预测尚未产生的随机数。无准备可查时提交非法，不收费；揭露与费用同步保存。对手可以不用隐藏目标的正面强攻 | 比普通将更早获得调整当轮位置的信息，但仍需自己做出正确反制 |

徐庶只揭露已经锁定、尚未公开的目标；黄忠未来第一个进入射程的敌队尚未确定，不能作为可揭露目标。当前回合依次处理准备提交、即时揭露与察伏、响应指令冻结，再处理行动。

魏延必须保存诱兵、追兵、原目标与提交回合；诱兵提交时无实际后退空间则拒绝，准备回合被消灭、未实际后退或下一回合目标已失效则取消。不凭空生成第二支同兵种队，不自动附赠“截击”，不假定当前已有枪兵阻截通行规则。

### 第二批名将 · v0.31.0

保留上述首批机制与公共计谋，第二批沿真实移动事件实现，不增加副将槽或免费伤害。正式身份仍绑定原有赵云／马超的 `wildLine`，画像、爵位、招降与共享唯一归属不改。

| 名将 | 两轮行动与代价 | 明确反制与失败条件 | 玩家需要改变什么 |
| --- | --- | --- | --- |
| 赵云 · 接应撤军 | 花 1 点，轻骑第 N 回合坚守准备并放弃主攻击；第 N+1 回合仍坚守，距另一支被保护己方队不超过 300。被保护队实际后退时最多按原速 1.5 倍撤退，同时消耗被保护队本轮主攻击 | 提交及响应检查距离，目标无后退空间则拒绝。接应骑兵阵亡、响应改令、超距或目标未实际后退则失效；后退受边界与火区限制，不传送、不增加攻击 | 先布置近距离接应，再让脆弱队撤离；在保留火力与撤退之间付出实际动作成本 |
| 马超 · 冲阵退敌 | 花 1 点，轻骑／重骑第 N 回合实际前进准备并放弃主攻击；第 N+1 回合仍真实推进，接触指定敌近战队后再牺牲本轮主攻击，推退最多 `min(目标速度/2, 200)` 向下取整 | 指定目标坚守完全抵消；距离不足、准备轮未前进、响应轮未真实推进或目标阵亡不触发。边界与火区可缩短推退，没有额外生命伤害，不连锁触发另一份主攻击 | 预测两轮间距离及敌方指令；用骑兵两轮攻击代价换有限位置改变，不能只靠提高伤害倍率 |

赵云响应轮只在实际接应后退时消耗被保护队的攻击，不把接应轻骑的响应轮攻击一并无条件扣掉。马超只在成功推退时消耗响应轮攻击，目标固守反制后仍按普通攻击预算执行。宣布、对象、揭露、失效原因、实际位移与攻击预算写入同一战斗账本。徐庶只揭露已经锁定的接应／冲阵目标，仍不预测未来命令。

后续候选仍包括关羽在缺口出现后追击，以及荀彧等内政将的运输统筹、城防预备与民心恢复；这些尚未实现。

### 正式军令战术遭遇 · v0.31.0

三场在任务册「战役军令」根据相应普通路线进度显示，不阻塞章节或原军令阶数。使用玩家真实将领与兵种，仍有行军、耗粮、永久战损、负重和普通军功；首次达成目标追加一次首奖，未达限损／限时仍保留普通胜利。与所属路线共享 10 分钟整军和在途限制。

| 遭遇 | 开放与目标 | 公开预兆与普通将应对 | 首奖 |
| --- | --- | --- | --- |
| 盾幕蓄弦 | 野战普通第 5 阶完成；获胜且永久损失 ≤20% | 盾枪护卫，弓队开战蓄弦；公共察伏、盾兵探阵、抢先进入或保持射程外可应对 | +45 军功 |
| 游骑诱阵 | 精锐普通第 7 阶完成；获胜且永久损失 ≤25% | 骑队诱退，后方枪弓待阵；被锁定近战队坚守／后退不追，弓兵仍可输出 | +55 军功 |
| 火隘截骑 | 攻坚普通第 10 阶完成；12 回合内获胜且永久损失 ≤30% | 营外截击无门墙；火攻类型公开，普通将观察后调整，徐庶提前揭区间；火区封路不扣血 | +70 军功 |

场景守将的计谋身份来自固定遭遇配置，另有明确来源校验，不是可俘获野将、不占共享名将归属。没有普遍给普通守军自动施计；既有普通挑战保留原敌方行为。

### 本城内政职责 · v0.32.0

荀彧真实招降后任本城城守且留城空闲，新资源运输行军粮减少20%并向上取整；货物、负重、去返时间及部队调遣保持原规则。庞统按同样身份／任职条件，在官府4、城墙2后支付本城木石铁各1000，准备一次正式守城门耐久增加20%。其他合格守将可指挥，正式开战消费准备快照，演练不消费、不加成，也不改变工事攻击。

卸任不丢失已付准备，但原筹备者需重新在本城任城守才能启用；迁城不把准备带走。已有队伍和正式战斗使用出发／开始时冻结记录，不中途回算。共享世界暂未开放这些职责。详细规格及验证见[领土与补给](../quick-specs/territory-supply-v0.32.0.md)与[本版验收](../../production/qa/territory-supply-v0.32.0.md)。

### 支持矩阵与反馈

| 模式 | 当前实现 | 前置与边界 |
| --- | --- | --- |
| 普通单机PvE逐回合战斗 | 五将身份、两个公共计谋、三场正式军令遭遇 | 新战斗使用 `rules:3`／计谋 `version:2`；沿现有速度、逐队移动、目标与即时反击规则加事件 |
| 独立教学 | 五场固定阵容，复用正式事件结算 | 不赠正式名将、不扣正式兵将／资源、不发正式奖励，至少两轮并观察实际效果 |
| 单机本城运输与正式守城 | 荀彧节约行军粮、庞统付费备防 | 真实招降、本城城守留城空闲；既有记录冻结，演练不消耗备防 |
| 已有计谋 `version:1` 战斗 | 保留首批规则与当前账本 | 不向进行中战斗注入赵云／马超能力，新出征再启用第二批 |
| 旧 `rules:2` 战斗 | 沿旧规则完成 | 不自动注入新计谋 |
| NPC守城 | 明确禁用位置计谋与新遭遇 | 当前没有逐队位置，接入前需先定义对应位置与行动模型 |
| 共享世界权威战斗、自动掠夺／援军 | 明确禁用位置计谋与新遭遇 | 阻止新遭遇派遣／开始；实现服务端权威事件、重放与场景契约后再启用 |

出征页显示“适合打法／发动条件／可破解方式”，不支持的模式明确提示。战报记录准备、揭露、识破、失效原因、动作消耗和战损；例如“黄忠张弓 → 盾兵进入射程 → 预备射击 → 本回合主攻击已使用”。察伏成功也说明“这次准备已取消”，不把取消表现为全军不能行动。

v0.29.0 三场演练展示预备射击与盾兵探阵、诱追与保持阵线、火区与提前揭露；v0.31.0 增加接应撤军、冲阵与固守，合计五场。教学至少观察两轮，实际效果目标达成后结束独立观察，支持重开；不要求歼灭全部固定守军。使用固定教学阵容，不赠送正式名将，不改变画像、爵位、招降容量或共享唯一归属。

v0.29.0 首批敌方自动施计限于明确设计的黄忠／魏延／徐庶野将身份与固定教学；v0.31.0 增加赵云／马超对应野将条件行为及上述固定军令遭遇。普通守军与其余军令挑战仍保留既有行动，不普遍应用开局火攻，避免无收益准备降低旧挑战难度。

## Edge Cases

- 施计兵队失去战斗力即取消关联准备；当前主将没有独立生命值，不创造“主将被单独击杀”条件。已经发生的攻击不回滚。
- 多个准备同时满足时按单位速度、现有同速守方优先、稳定单位ID排序；一个移动事件最多触发一项同队准备。触发目标已死不自动换成更有利目标。
- 第N+1回合准备队已普通攻击则不能再触发；黄忠待触发队应保留攻击机会，整轮未触发也算落空。合法反击仍按现规则处理。
- 魏延目标改坚守／后退时保留原目标；诱兵阵亡即取消强制追击。到边界、超回合、城门和30回合结束仍按公开场景规则处理。
- 存档、重载与服务器重试保存筹策、预兆、目标、行动额度、规则版本与已揭露信息；同命令不得二次扣费或触发。
- 旧将按稳定wildLine映射身份；普通将保留公共计谋。旧已开始的战斗沿旧规则结束，不临时注入新机制。
- 已有计谋 `version:1` 的身份仍按首批映射校验，筹策、预留攻击和事件无需重置；第二批不迁入该快照。新版 `version:2` 接应／冲阵目标、实际位移及攻击消耗必须完整校验。
- 马超强制推退沿边界和火区裁剪，不能被当作目标主动移动再连锁产生第二份主攻击；赵云只有实际合法后退才记一次接应效果。

## Dependencies

| 系统 | 契约与待办 |
| --- | --- |
| 将领定义／成长 | 身份绑定wildLine，与专长独立；当前属性及费用不在本稿改价 |
| 战斗事件 | 准备、提交目标、真实移动、主攻击预算、即时反击和失效记录；严格存档校验须一起扩展 |
| UI与演练 | 可读预兆、费用、隐藏／揭露边界与原因；失败可低成本重试，自动策略需真实演练 |
| NPC／共享结算 | 接入前先定义场景契约，不通过复制一个技能分支宣称三模式支持 |
| 服务端与存档 | 出征冻结身份和规则版本；旧快照、CAS、幂等与离线信息不能绕过费用 |

目前没有entity registry或正式systems-index，原型数字不注册为正式全游戏事实。

## Acceptance Criteria

- GIVEN 普通将领，WHEN 面对黄忠准备，THEN 可以用固守、盾兵探阵或公共察伏反制，无需另一位唯一名将。
- GIVEN 敌队本次实际从射程外移入黄忠弓队射程，WHEN 预备仍有效，THEN 弓队只用一次主攻击，日志区分准备射击与合法反击。
- GIVEN 敌队已在射程内或停在射程外，WHEN 本轮没有新进入事件，THEN 黄忠不触发，整轮结束失效。
- GIVEN 魏延选择的追兵改为坚守，WHEN 第N+1回合执行，THEN 不强迫前进、不改它的攻击目标，日志解释诱追失败。
- GIVEN 魏延诱兵不足目标训练成本1/3或没有后退空间，WHEN 提交，THEN 拒绝且不收费；合法后未退则失效不退款。
- GIVEN 徐庶揭露已提交火区，WHEN 调整第N回合位置，THEN 得到确切区间但不取消火攻；无未来命令泄露。
- GIVEN 公共察伏选定黄忠准备队，WHEN 当前回合移动前处理，THEN 仅取消该准备且双方成本不退，不禁止无关队行动。
- GIVEN 火区生效，WHEN 任意一方单位实际跨入，THEN 停在边界外1单位且没有额外生命伤害；生效时区内已有队伍则全段失效。
- GIVEN 已消耗筹策的战斗，WHEN 重载或重试相同命令，THEN 费用、揭露、攻击机会与效果不重复。
- GIVEN 未接入的守城／共享模式，WHEN 选择新机制，THEN 明确禁用，不静默忽略或擅自换一套倍率。
- GIVEN 赵云已准备接应，WHEN 下一轮附近被保护队真实后退且轻骑仍坚守，THEN 只在合法范围内增加后退距离并消耗被保护队本轮主攻击；超距或骑兵阵亡则失效。
- GIVEN 马超准备轮真实前进，WHEN 响应轮推进接触指定敌近战队，THEN 以本轮主攻击换有限推退；目标坚守完全反制，没有额外生命伤害。
- GIVEN 旧计谋 `version:1` 战斗，WHEN 重载并继续，THEN 保留首批身份、筹策、准备和事件，不注入第二批能力或重复扣费。
- GIVEN 军令遭遇首次达标，WHEN 战斗结算／重载／重复尝试，THEN 首奖只结算一次，未达挑战条件仍保留普通胜利。
- GIVEN 后续两模式已接入，WHEN 比较相同标准化事件，THEN 条件及筹策／动作消耗一致；仅场景规则也一致时比较最终战损。
- GIVEN 未看源码的试玩者，WHEN 完成五场演练，THEN 能解释至少两位将为何要用不同指令；需真人观察，当前 NOT ASSESSED。
