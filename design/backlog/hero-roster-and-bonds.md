# 备案 · 扩充武将后重做羁绊

- 日期：2026-10-09 · 状态：备案（待排期）
- 来源：负责人反馈 v0.34.42 的 6 组羁绊「一点联系没有」。v0.34.43 起羁绊效果与面板关闭，旧组合保留在 `hero-bonds.js` 的 `archived` 里。
- 原则：羁绊必须来自史实或演义里的明确关系（结义、主从、同门、并称、宿敌），组合里的武将都要能在游戏里获得。

## 1. 现有可获得的武将（v0.34.42）

| 来源 | 武将 |
|---|---|
| 初始 | 林朔、苏砚（原创）、严秋（黄巾营寨） |
| 野地画像 | 陈岚（原创）、魏延、徐庶、赵云、黄忠、甘宁、张辽、马超、荀彧、庞统、周瑜、关羽 |
| 名将镇守名城 | 张飞（小沛）、典韦（宛城）、吕布（下邳）、太史慈（北海） |
| 客栈 | 随机原创游士 |

史实关系很难凑成对：例如有关羽、张飞却没有刘备，有周瑜却没有孙策，有典韦却没有许褚。

## 4. 前置工作

1. 为每位新武将写数值、身份战法（`battle-stratagems.js`）与获得方式。
2. 野地画像 / 名城镇守 / 剧情事件三种获得途径的配额，避免全部堆在名城上。
3. 羁绊效果统一接到现有钩子：属性（`HeroSystem.bonus`）、战斗攻防与行军（`HeroBonds.battle`），筹策和火攻需要扩展 `BattleStratagems`。
4. 用 `tests/balance/chapter-four.cjs` 和名城模拟验证羁绊加成不会让第四章规则失效。
