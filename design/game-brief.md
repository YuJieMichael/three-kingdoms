# Game Brief：三国城志

状态：2026-10-05，依据现有游戏与用户已选方向整理；后续设计为草案，尚未改动玩法。

**One-sentence pitch：** 从一座小城起家，靠经营、侦察、配兵和各有所长的将领夺取城池，与盟友争夺三国疆域。

## Core loop

- 经营城池、安排研究与补兵，积累下一次行动的物资。
- 打听将领、侦察目标，选择主将、兵种、路线和风险。
- 出征、指挥、缴获或占领，读懂战损和收益。
- 运回补给、培养将领、经营新城，挑战更有价值的目标。

## Player goal & fail state

当前单机阶段目标为弓兵首胜、画像抓将、黄巾史诗与县城；失败产生战损并允许整备重试。后续多人目标拟为协同争夺重要城市，城池损失后的恢复路线需先设计，避免失败导致永久无法继续。

## MVP

- 城建与四资源经济、明确的新手目标和十阶礼包。
- 弓兵主力、步兵掩护、骑兵奔袭、器械攻坚的用途。
- 可读的行军、侦察、战斗、返回与战后账本。
- 画像寻将、招降、培养与有区别的主将选择。
- 多城分工、运输调遣和守城。
- 手机与电脑可操作、可靠存档；共享世界单独验收。

## Out of scope

下一阶段先不扩充整套坐骑／宝石／付费数值养成，也不把原版所有系统同时搬入；百人正式运营、即时手动PVP和赛季重置尚需独立规格与实际部署验收。

## Build order

1. 已有经营—弓兵—首胜循环与多城物流，继续校准衔接。
2. 先统一战斗事件契约，用三位将领和少量可反制计谋验证不同打法。
3. 用教学战验证选择，随后扩展名将；建立黄巾城市到县城／郡城的后期目标链。
4. 确定宣战、保护、经济和败方恢复规则，再完成真实多人服务与容量验收。

**Who it's for / what they feel：** 喜欢经营与三国策略、每天分段游玩的玩家；靠判断和准备取得胜利，出门后城池也在发展。

**Art & audio direction：** 写实古代战争，清楚紧凑的城池与军情界面；声音反馈先服务于行动与战损辨识。

**Reference game：** 早期《热血三国》的城建、配兵、野地抓将与疆域争夺，结合本作的弓兵引导和手机操作。
