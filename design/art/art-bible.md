# 美术规范 · 精致国风手绘

- 版本：v0.34.31（2026-10-08） · 任务：TR-art-direction-001
- 适用：从 v0.34.26 起的全部新素材（建筑、建筑等级外观、地图物件与纹理、将领、道具）
- 提示词原文：[building-prompts-style1.md](building-prompts-style1.md)

## 1. 风格定位

**一句话：** 东汉末年的城池与山河，精致手绘，明亮午后光，像高品质国产 SLG 主城的画法。

- 写实偏绘画：轮廓清晰，体积柔和，细节丰富。不做卡通、低多边形、扁平矢量，也不做照片。
- 时代：东汉末年（三国）。灰色筒瓦曲面屋顶，檐口微翘，斗拱，朱漆柱，夯土墙和青砖墙，石台基。不出现明清式的琉璃瓦、彩画满铺和高翘飞檐。
- 情绪：安定、繁荣、可经营。战争感交给战斗画面和红黄旗帜，城内建筑不画火光和破损。
- 参考方向：《率土之滨》《三国志·战略版》的主城和大地图（只参考画法和视角，不照搬任何图形）。

## 2. 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 屋瓦 · 墨灰 | `#5b5f63` – `#7b7f80` | 建筑主色，屋顶占画面最大面积 |
| 柱子 · 朱红 | `#a8422e` | 与界面 `--red` 一致，只作点缀 |

| 墙 · 夯土与青砖 | `#d8cfb3` / `#9a9a8c` | 院墙、城墙 |
| 点缀 · 玉绿 | `#527442` | 松柏、竹，与界面 `--green` 一致 |
| 城坊地面 | `#8b9368` | `.scene-scroll` 底色，建筑图要在它上面清楚 |
| 地图草地 | `#8fae5f` | 无纹理时的草地底色 |
| 地图丘陵 · 赭土 | `#b9a06a` | 丘陵与荒地 |
| 地图森林 | `#4f7d4c` | 森林区域底色 |
| 地图湖水 | 青绿，以 `lake.avif` 纹理为准 | 湖边有一圈沙色 |
| 界面纸色 | `#eee2c9` / `#e5d4b4` | 面板，素材不要用这么浅的大面积底色 |

## 3. 光照与视角

- **光源：左上方的暖色午后阳光。** 阴影落在右下方，只保留建筑底部很淡的接地阴影，不画大面积投影（游戏里另有地面层）。
- **视角：严格 2:1 等距**（俯视约 30°，旋转 45°）。建筑底座落在一个看不见的菱形上，菱形左右两边按「横 2 竖 1」上升。
- 地图物件用约 45° 俯视，与等距城坊保持一致的观感。
- 不出现透视消失点、天空和地平线。

## 4. 比例与占地

| 类别 | 占地 | 画面要求 |
|---|---|---|
| 官府 | 2×2 | 明显大于其他建筑；游戏中显示框 250×212 |
| 其他城内建筑 | 1×1 | 同一套建筑高矮相近，大小差别只来自建筑本身 |
| 城墙 · 城门 | 城门位 | 城墙由代码画砖墙，图片只出城门楼 |
| 城外资源田（农田、伐木场、采石场、铁矿） | 田地 1 格 | 不带自己的草皮、土台或菱形底座 |
| 地图物件（山、林、城池、营寨） | 不超出 1 格 | 底部居中贴在格子里，四周留边 |
| 地图纹理（草地、湖面） | 平铺 | 无缝四方连续，不透明 |

## 5. 交付规格

**生成：** 透明背景 PNG，1024×1024，主体完整，四周留一点透明边。纹理是不透明的无缝图。

**处理：** 用 `tools/painted-art/process.sh` 一条命令完成下面 1–4 步（需要 macOS，见 [tools/painted-art/README.md](../../tools/painted-art/README.md)）。

1. 裁掉透明边（alpha 不为 0 的包围框）。
2. 缩放：建筑长边 **512px**；地图物件长边 **384px**；纹理 **512×512**，不裁边。
3. 转成 **AVIF**（主用）。
4. 同时生成同尺寸 **PNG 备用图**（给不支持 AVIF 的旧设备，例如 iOS 15 及以前），用 pngquant 压缩：`pngquant --quality=65-90 --speed 1 --strip`。全部 PNG 备用图合计不超过 6MB（现在约 3.2MB）。
5. 地图物件要把「高 ÷ 宽」写进 `painted-art.js` 的 `PaintedArt.map`，地图才能按原比例显示。

**命名和目录：**

- `assets/painted/buildings/<建筑 id>.avif` 和 `.png`，id 与 `Game.buildings` 一致（如 `hall`、`academy`）。
- `assets/painted/map/<物件名>.avif` 和 `.png`，小写英文，变体用 `-a`、`-b`（如 `mountain-a`）。
- 换图时把 `PaintedArt.version` 加 1，让浏览器重新下载。
- 等级外观（以后做）：`<建筑 id>-l1`、`-l2`、`-l3`，分别对应初级、中级、高级。

**接入：** 所有手绘图都通过 `PaintedArt.src(kind,id)` 取地址；启动时检测一次 AVIF，不支持就整体换成 PNG。不要在别处直接写 `.avif` 路径。

## 6. 提示词结构

每条提示词 = **主体** + **通用风格** + （可选）**等级后缀**。

- 建筑通用风格、20 座建筑主体、等级后缀、施工中：见 [building-prompts-style1.md](building-prompts-style1.md) 前半部分。
- 地图通用风格和地形主体：同一文件「大地图地形素材」部分。
- 新增一类素材（例如将领立绘）时，先在提示词文件里写它自己的通用风格，第一张通过后再批量出图。
- 同一批图放在同一个 ChatGPT 对话里生成，并说「保持和上一张完全相同的画风、视角和光照」。

## 8. 已知缺口与优先级

| 优先级 | 缺口 | 现状 | 建议 |
|---|---|---|---|
| P1 | 建筑等级外观（初、中、高级） | 1 级和 20 级长得一样，升级没有视觉回报 | 先做官府、民房、城墙三套，用等级后缀出图，命名 `-l1/-l2/-l3` |
| P1 | 将领立绘 | 将领页只有文字或旧头像 | 先写「将领立绘通用风格」（半身、同一光照和画框），再从主要将领开始 |
| P2 | 道具图标 | 背包和商城多为文字或简单图形 | 统一 128px 方形图标，同一光照，透明背景 |
| P2 | 施工中外观 | 建造时只有进度条 | 用「施工中」提示词出一张通用脚手架叠加图 |
| P3 | 城外底景重画 | `outskirts-ac-v1.png` 比新建筑粗糙 | 按本规范重画一张宽幅底景 |
| P3 | 战斗兵种图 | 战斗用色块和文字 | 等战斗画面改版时一起做 |
