# v0.25.1 · 抓将画像前置

用户补充：购买画像后才能抓到野地将领。沿用 v0.25.0 的骑兵奔袭、手动招降、忠诚培养与战后自动返回地图。

- 客栈打听 → 商城或客栈画像专柜购买对应将领画像 → 出征歼灭全部守军 → 俘获 → 手动支付黄金或珍宝招降。
- 画像价格采用本作试玩值：陈岚10、魏延30、徐庶50元宝，使用现有元宝余额，无充值。已发现对应线索才能购买，购买后永久拥有，战败、胜利、释放和重新打听均不消耗。
- 无画像的正常出征仍可战斗并拿普通战利品，但不俘将、不占房，战报与配兵预览明确提示。先占领而未俘获的将领可免费重新打听新落脚点，保留该将ID、属性、画像与其他线索。
- 购买执行时再次核对报价、线索、余额和是否拥有；防重复扣款，受存档写保护限制。旧档没有画像字段迁移为空，已俘或已招降将领不追缴画像。
- 画像入口位于商城、客栈抓将面板和地图目标提示，首页显示首位画像缺额。该收藏独立于既有尚未接入的武魂画像宝物。
- 修正旧章节 UI fixtures：解锁章节只显示已探索及当前站，仍保留第二章六关占领门槛和未来站按钮防护。

本轮仅做必要定向测试，既有 GitHub CI 正常随发布运行。大型本地回归、真机触屏、自然成长节奏和后续联网抢将继续按用户要求另轮进行。
