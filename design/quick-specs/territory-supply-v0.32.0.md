# v0.32.0 领土与补给

用户选择建议1、2、3，三项一起实施。CCGS minimal dev-story → story-done；现有平铺浏览器JS引擎。状态：IMPLEMENTED PROTOTYPE，COMPLETE WITH NOTES。

区域战线只在已拥有的固定粮城、矿城、关隘开启。每城独立的三阶段守城，玩家主动开始每一波，至少五分钟预警；现有真实驻军、守将和工事参与，运输与调遣可以提前增援。失败沿现有守城损失规则，不丢失城市；可准备后重试。奖励通过实际守城资源入库及军功结算，首奖去重，完成整轮后冷却三十分钟再主动重开，重复守城只有普通维持奖励。未开启、预警到时、离线都不自动打仗。

自动补给保存来源城、目的城、资源、目标库存、来源保留和固定运输队，最多十二条。同方向同资源不重复，同线去程／返程合计最多一队。目的库存加未送达货物达到目标就等待；不满足库存、兵力、市场、校场、行军粮或负重条件则明确显示原因。发队复用真实运输报价／支付／到达／返回，不瞬移资源，允许实际到达入库爆仓。召回会暂停所属线路。在线挂机按当前库存调度；离线结算已经出发队伍，重新打开按当前库存派下一趟，不追补历史重复往返。各城显示当前净粮消耗与按现存库存估算的可维持时长。

荀彧任本城城守时，新派资源运输的行军粮减少20%，不改变货物、负重或已有队伍记录，不影响部队调遣。庞统任城守且官府4／城墙2后，可付木石铁各1000备防一次；下一场正式守城门耐久增加20%，可由其他守将指挥，正式开始时消费一次，演练不消费、不增幅。预备绑定本城；卸任时暂不可用。真实在野招降身份、画像、爵位及容量继续有效，不通过姓名认定身份。

沿用五入口；功能放现有城池、地图目标、运输和将领详情，长说明折叠，不新增主导航。新区域／补给／主动备防先用于单机，权威共享状态明确阻止未接入命令；既有云存档兼容及运行时副本仍构建、定向检查，不部署远程服务。参数为有界试玩设计，不宣称自然经济已调平。

必要检查：真实资源守恒、重复发队／奖励、跨城隔离、旧档迁移、进行中队伍／战斗冻结、伪造数据拒绝、只读／共享守卫、桌面与390px手机实际操作。大型本地全量、自然长局、真人平衡按用户安排另批集中做。

实际验收：158项唯一必要检查通过，29源权威副本构建、两种视口11张已观察证据；[验收记录](../../production/qa/territory-supply-v0.32.0.md)。试玩平衡与线上服务边界保留。
