# 城守建造经验

Status: Complete
Last Updated: 2026-10-05
类型：Logic / UI；系统：建筑完工、将领成长；代码根：项目根目录的原生浏览器 JavaScript。

依据：用户要求“作为城守每个建筑完成了都可以获得经验”。沿用现有建筑队列和 HeroSystem 升级规则，不需要新增存档结构。项目为 minimal 工作流，无关联 ADR、TR registry 或 control manifest。无需引入引擎或依赖。

规则：每个城内建筑或城外资源田完成新建、升级、改建后，完工时的城守获得 **完工等级 ×10 经验**。一级 10，十级 100；不随倍率、原工期或使用加速改变。经验沿用每级当前等级 ×80 的阈值、溢出保留及每级三个自由属性点。此数值是初始试玩规则。

换任前先结算已经到期的工程：到期时原城守任职，经验归原城守；尚未完成的工程以后归新城守。开工、取消、拆除和迁移不给经验。现有已竣工建筑不追补，升级前未完工队列在完成后正常奖励。关闭完成通知不影响经验。

统一在 tick 的 build 完工分支结算，移除队列和经验同步保存；自然计时、加速、自动建设、离线与导入均使用同一入口，重复 tick/重载不重复发放。建设/升级确认显示奖励，助手完成记录保留城守名字和获得经验，将领界面说明经验来源。

验收：

- [x] 城内建筑和资源田的新建/升级/改建按完工等级发放。
- [x] 取消、拆除、迁移和开工不发经验。
- [x] 加速、自动、离线与重载仅结算一次，通知开关不影响所得。
- [x] 换任前后、多个工程、旧存档未完工队列的奖励归属正确。
- [x] 升级、溢出及自由属性点沿用原规则，界面和完成记录可见。
- [x] 桌面及手机页面核验并保留截图；Graphify 按既有本地 code-only 参数刷新。

测试：虽然 minimal 工作流不强制单测，本功能涉及持久经验和时间归属，主动增加行为回归 tests/governor-construction-xp.test.cjs，并运行现有完整套件。其余测评问题和经济奖励不在此更新范围。

结果：新增 10 项行为回归及完整 105 项全部通过；独立源码复核未发现新增阻塞。浏览器正常领取首阶礼包的新档，通过界面建造民房并使用合法加速，苏砚经验从 0 到 10，助手记录一致。1280、390、360 像素检查完成，详见 production/qa/governor-construction-xp-v0.22.0.md。
