## 规则与验收

- [x] **SAVE-01** 同源页面只有一个活跃写者。第二页面只读，明确接管必须加载最新保存数据；旧页面检测写者或原始存档版本变化后停止队列、战斗、自动保存和操作，不能覆盖新进度。正常重载/离线结算兼容；关闭或异常退出由浏览器释放独占锁，冻结写者不会被租期超时强抢。
- [x] **SAVE-02** 保存保留最近有效快照。读取异常、无效存档不自动写新城覆盖原始数据；提供重新读取、原始数据导出、有效备份恢复和已有导入入口。恢复/导入重新校验，替换前保留旧数据，失败不伪报成功。
- [x] **ECON-01** 全量核算任务与礼包及消费；减少早期重复超额奖励，不扣回已领取奖励。保留十阶礼包现有黄金总量、掠夺/占领/采集爆仓和市场规则。合法模拟首弓<90分钟；不加点的固定路线12seed十阶24–48小时，内政优化23.33小时变体单列，提供账本与多个种子证据；不将自动路线时间称真人时间。
- [x] **GROW-01** 城守首个可培养点有可选提示/入口，说明内政对新工程的收益但不强迫加点；十级后接具体史诗、章节与军令目标，显示前置/科研/配兵缺口并可直接前往。
- [x] **WAR-01** 护械新挑战需器械实际击中城防至少一次且战场存活≥80%；旧完成记录和旧战报兼容且不追回。增加两项有不同阵型/战术取舍的后期可选目标，弓兵仍为主力，避免只加血量阶数。
- [x] **BATCH-01** 未结束战斗可全军固守/前进/后退，只影响存活我军，保留目标和逐队调整；无效指令与结束战斗拒绝，战报/结算不重复。
- [x] **BATCH-02** 俘虏一键招降按稳定兵种顺序选择可负担最大量，跳过未解锁兵种；预览数量、费用、人口及留营原因，确认重新核对计划，资源/人口/俘虏及任务计数只结算一次。
- [x] **UI-01** 手机360/390内容区增加、成长卡短目标可展开、资源发现提示常驻、关键小字可读；加速优先拥有/少浪费规格，保留实际缩短与溢出预览，零库存不可确认。
- [x] **ART-01** 写实古代战争方向，沿用现有图标/源生SVG系统，增强地形连续、道路/水系、据点和等级/选中/归属层次；城外资源田具有类型与施工状态。原地图移动、选择、侦察、出征、资源田建造/升级仍可用。
- [x] **QA-01** 完整回归、定向存档/批量操作/兼容测试、合法经济模拟、实际桌面与手机浏览器截图和独立审阅；本地Graphify以同参数code-only刷新。版本/发布记录按实际结果填写。
