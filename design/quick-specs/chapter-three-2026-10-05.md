# 第三章与正常推进验证（最小规格）

用户授权：完成第二章平衡实测、第三章攻城、挂机助手、手机优化。本规格覆盖前两项。

目标：北境大营占领后开启五关河洛战线。第一关野战→东门→骑营→重墙→内城，掠夺不推进章节，占领与一次性任务奖励沿用既有存档字段。第二章节点、任务 ID 和默认 progress API 保留。

实现：ChapterData.allNodes() 合并两章；章三各节点提供原创敌将（攻击、防御倍率与坚守/主动推进）。SiegeSystem 负责门墙耐久、器械伤害、射程和防护。战斗保存可变 gate HP；城防攻击是可选择目标，冲车/投石车优先破门。必须同时清空守军、破门才能赢得占领。城防破坏解除倍率防护并停射箭楼，掠夺不启用门墙。五关的门墙耐久与箭楼射程不同，骑营敌军主动迎战。

器械获得：无城防的前哨通关领取 5 冲车，东门通关领取 2 投石车，显示“盟军试作援军”。一次性领奖支持军队，正常生产保留原军营与科技门槛。无货币交易/充值。资源、将领、兵种数据均沿用现有游戏，剧情敌将与门墙数值为本项目原创。

验收：旧章二任务测试仍通过；章三锁定与掠夺/占领分离；器械对门墙伤害明显优于同数普通部队；破门、清军两条件；破门后箭楼不再伤人；重载保持门墙损伤且拒绝损坏门墙存档；援军领取一次；正常建造/科技/训练产生的军队通关，保留耗时、资源、损失记录。

工作流：CCGS team-combat minimal gameplay-programmer 实现；combat-designer 与 balance-designer 关注点在同一执行流程顺序检查，没有独立专家审批或独立引擎评审。程序测试不能替代桌面/手机视觉与交互验收，由主任务执行后报告证据。
