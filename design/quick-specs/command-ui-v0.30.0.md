# v0.30.0 指挥界面精简

用户选择前五项界面更新：合并导航、统一当前目标、突出地图、压缩军队与将领名册、聚焦战斗。保持现有战争美术，不改变战斗、成长、资源或云端规则。

主导航为城池、地图、军队、将领、更多。城内外作为城池子页；队列、背包、任务直接触达，礼包全部领取后退出常驻工具栏。当前目标使用实际成长模型，阶段与任务记录保留在详情，避免三处重复占屏。地图保留行军与目标操作，辅助地图信息按需展开。军队/将领的完整能力、费用与培养在详情，显著初始属性只染数值。战斗保留指令、射程、计谋与计时，长回顾可展开。

重要信号：驻外部队、到达/返回、来袭、负粮产量、超仓和实际装载/入库仍可见或一跳查阅；存档只读保护和共享状态必须继续工作。以独立存档做手机/桌面浏览器验收，不动用户正在玩的城池。大型本地回归、自然长局与真人可用性测评继续按用户要求集中安排。
