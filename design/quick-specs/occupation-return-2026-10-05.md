# 野地占领后返回选项

用户要求：占领的时候可以选择占领后返回，不选就是驻扎。

## 验收

- 可驻扎野地的占领配兵页增加「占领后返回」复选框，默认不勾选。勾选胜利后返城；不勾选沿用驻扎、双倍耗粮与采集规则。
- 每支出征队伍保存本次选择，刷新、切换队伍与恢复战斗保留；旧存档没有该字段时仍驻扎，不改变已经在途的计划。
- 勾选返城仅改变胜后的兵力去向，野地归属、名额、产量加成、战利品、经验、冷却和负重保持相同；失败仍返城。返回过程按既有行军计时，不能重复调回或发奖。
- 掠夺、任务据点和军令保留原有返城行为。v0.23.4 时仅野地有驻扎选择；v0.34.34 起占领城池（县城、黄巾城等）也有：默认主将与部队留守新城（出征界面写明），勾选「占领后返回」则返城。没有可出征将领时说明原因。掠夺模式隐藏并禁用选择；同一次表单切换模式保留勾选状态。
- 配兵说明、在外部队和结果说明与选择一致；窄屏可点选、无溢出。正常 API 生命周期回归与实际浏览器截图完成后发布 v0.23.4。

## 变更记录
