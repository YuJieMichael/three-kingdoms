# v0.25.0 · 据点进度与征战闭环

状态：IMPLEMENTED，必要集成验收通过；发布提交与线上资源校验记录在工作区 outputs/update-v0.25.0/publish-receipt.json。
用户范围：任务据点逐站显示，以及战斗反馈、野地抓将、主动黄巾来袭、首页主线和补给衔接五项更新。大型本地回归与长局按用户要求延期，本轮只做必要的功能和存档检查；既有 GitHub CI 随发布运行。

- 地图保留已经探索、占领、驻军或派遣的据点，显示下一站，未来站点隐藏；第一章资源据点掠夺胜利即可探索，黄巾营寨需占领。章节仍按原占领条件推进，第三章仍需第二章六关全部占领。旧档的后续进度不回退。
- 战斗仅添加观察事件，不改伤害、命令或时间公式。当前回合列出攻击者、目标、伤害和倒下人数，动画尊重减少动态设置，恢复存档不重播。战斗结束自动回地图，无需确认关闭战报；地图保留简要结果，完整结果在战报。战后列出装载、实际入库、永久损失补兵成本，伤兵、道具、珠宝和装备各自保留原单位。
- 野地将领通过客栈稳定线索寻找，正常击败全部守军后俘获，手动以黄金或珍宝招降。首位陈岚走轻骑兵快速抓将路线（不限制其他兵种），无需爵位；魏延、徐庶要求爵位。俘将占招贤馆空位，满员释放。新俘获忠诚40，原有与客栈将领80，赏赐提升，不添加逃亡惩罚。
- 行军按最慢参战兵种速度计算，以弓兵基础速度250作为既有路程参考；轻骑兵基础1000更快，混编慢兵拖慢全队。新派遣/返程采用当时科技速度和倍率，旧在途时间戳保留，不接入在线PvP。
- 主动黄巾来袭需官府2级与出征首胜，五分钟预警。玩家选择空闲守将和驻城部队，实际工事参与防御。新档默认无自动来袭，旧档保留旧自动节奏。关闭后续周期不取消正在到来的敌军。
- 首页显示建立城池→弓兵首胜→招降野将→黄巾史诗→首座县城的真实目标、差额与奖励。绑定现有任务，新增四资源各3000的招降一次性任务，重复领取禁止。
- 首胜补给改为四资源各6000、黄金6000；粮田任务改为粮石各4000、木铁各3000、黄金8000。不补发旧已领任务。普通3级起网格野地掠夺基础资源额外乘2，原掠夺1.3、复战0.6与负重上限仍适用。首页补给账本核算最近五场实际掠夺与永久补兵资源，不宣称完整利润。
