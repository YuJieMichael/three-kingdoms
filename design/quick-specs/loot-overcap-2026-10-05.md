# 掠夺、占领与驻军采集允许爆仓

用户要求（2026-10-05）：掠夺或者占领或者驻地采集如果资源超了也可以直接爆仓。

## 规则与验收

1. 胜利已装载的基础与随机资源全部入库，仓储容量不截断；满仓、已超仓、部分空位均可结算。保持幸存部队共用负重，伤兵不搬运，失败不获得资源。
2. 野地采集按原公式、真实时间至少一小时及最多二十四小时累计；收取量由驻军负重限制，仓储空位只作说明。实际收取量决定将领经验；珍宝逻辑与一次收取保留。
3. 预览与真实结算统一，标明爆仓部分包含在入库中。保存可选 overCapacity 字段；旧 overflow 继续表示未入库损失，旧战报与历史记录不改写、不补发。
4. 资源田保留自然生产上限：超仓不删除库存，消耗至容量以下再增产。默认仓储结算仍用于守城及其他原有来源；新增逻辑只用于进攻和采集。
5. 数值保留合法存档上限 Number.MAX_SAFE_INTEGER，避免极端输入破坏存档。

## 验证计划

独立接口回归覆盖掠夺/占领、黄金、随机资源共用负重、采集一小时/二十四小时、旧记录、新字段校验、失败和一次结算。实际隔离浏览器导入正常 API checkpoint，验证出征预览、战报、采集预览/收取、桌面与窄屏排版；线上玩家存档不导入或重置。回归与浏览器证据完成后发布 v0.23.3。
